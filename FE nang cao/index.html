🌸 Nhật Ký Học Tập Front-End

✨ Hôm nay em học được gì?
Học cách xây dựng giao diện tương thích đa thiết bị (Responsive Web Design) sử dụng các điểm dừng @media query (cho màn hình điện thoại, máy tính bảng) và thiết lập chế độ in ấn với @media only print. Ngoài ra còn biết cách sử dụng thẻ <picture> kết hợp với thuộc tính srcset và media để tối ưu hóa hình ảnh linh hoạt theo kích thước màn hình.
💻 Hôm nay em đã làm được gì?
Hoàn thành bài tập chia bố cục trang web dạng cột trái (Left) và cột phải (Right), tùy chỉnh kích thước ảnh tự động co giãn trong khối, đồng thời thực hành mẹo lập trình JavaScript trên bảng điều khiển Console của trình duyệt (thay đổi hàm kết thúc game Dino và tốc độ chạy của khủng long).

🦖 Tổng Hợp Đoạn Code Thực Hành

1. Lệnh Console chỉnh sửa Game Dino (Bất tử & Tốc độ):
this.gameOver = () => {};
this.gameOver = function() {};
this.setSpeed(10000);
2. Cú pháp Media Query Responsive & Print mẫu:
@media only screen and (max-width: 768px) {
  .left, .right { width: 100%; }
}
@media only print {
  .left { display: none; }
}
