## Tiến độ mã nguồn
- **Lab 08 – JavaScript 1: Language Foundations:** hiện có 11 Exercise.
- **Lab 09 – JavaScript 2: DOM and Events:** chưa có mã nguồn trong file ZIP đầu vào; cần bổ sung các Exercise theo tài liệu Lab 09.
- **Lab 10 – JavaScript 3: jQuery:** chưa có mã nguồn trong file ZIP đầu vào; cần bổ sung các Exercise theo tài liệu Lab 10.

Các liên kết Lab 09 và Lab 10 trên trang chủ được tạo để giữ cấu trúc điều hướng, nhưng hiện chỉ dẫn đến trang thông báo, không phải bài thực hành đã hoàn thành.

## Cập nhật trước khi nộp
1. Thay `Lớp học phần` trong `index.html` và README bằng mã lớp thực tế.
2. Nếu muốn dùng ảnh cá nhân, thay `images/avatar.svg` bằng ảnh của mình và cập nhật đường dẫn trong `index.html`.
3. Bổ sung mã nguồn đầy đủ của Lab 09 và Lab 10 vào hai thư mục tương ứng.
4. Đưa thư mục `JavaScript-Labs` vào repository GitHub hiện có, không xóa các nội dung cũ.
5. Bật GitHub Pages theo nhánh/thư mục đang sử dụng và kiểm tra các đường dẫn sau khi triển khai.

## Cách kiểm tra
Mở `index.html` bằng trình duyệt hoặc truy cập trang GitHub Pages sau khi triển khai. Trong các Exercise, nhấn **F12 → Console** để xem thông báo và lỗi JavaScript.
